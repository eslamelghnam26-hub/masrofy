# مصروفي (Masrofy)

تطبيق إدارة مصاريف شخصية — **نسخة مستقلة 100% بدون إنترنت**، جاهزة كقالب مصدر كود.  
كل البيانات تُحفظ على جهاز المستخدم عبر `shared_preferences` فقط. لا خدمات سحابية ولا حسابات خارجية ولا خوادم.

## المميزات

- إضافة وتعديل وحذف المصروفات والدخل محلياً.
- تصنيفات أساسية ومخصّصة، وميزانية شهرية لكل تصنيف.
- لوحة رئيسية للرصيد والدخل والمصروفات مع تقارير ورسم بياني.
- منتقي شهور، وحذف بالسحب للعمليات.
- عربي/إنجليزي مع RTL/LTR، وثلاث ثيمات (أخضر / كريمي / داكن).
- دخول محلي تجريبي برقم هاتف وكود ثابت `1234` (لا SMS ولا حساب خارجي).
- جلسة محلية محفوظة على الجهاز بين فتحات التطبيق.

## التشغيل

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

لبناء APK:

```bash
flutter build apk --release
```

الملف: `build/app/outputs/flutter-apk/app-release.apk`.

## التخزين

لا يوجد أي اتصال بالشبكة. مفتاح الحفظ المحلي:

- `masrofy.transactions.v1` — العمليات
- `masrofy.customCategories.v1` — التصنيفات المخصّصة
- `masrofy.budgets.v1` — الميزانيات
- `masrofy.theme.v1` / `masrofy.language.v1` / `masrofy.loggedIn.v1`

## ملاحظات للبيع كقالب

- لا توجد مفاتيح أو ملفات إعداد خدمة خارجية في المشروع.
- يمكن تغيير اسم الحزمة/الشعار/الألوان من `android/app/build.gradle.kts` و`assets/`.
- رمز الدخول `1234` في `lib/services/auth_service.dart` قابل للتعديل بسهولة.
